TideSurf

Agents can browse live pages as text.

TideSurf is the DOM-to-text runtime for engineers building function-calling browser agents.

A compression layer between Chromium and your LLM. Live pages become token-efficient text with stable element IDs, so agents can browse, reason, and act without brittle selectors.

How it works

Compressed DOM for agents.

01

Connect

Attach to Chromium over CDP. Launch headless or connect to a browser you already have open.

02

Compress

Rendered DOM becomes token-efficient text. Typical page: 50-200 tokens. Parse in under 25 ms.

03

Act

Your model picks a stable ID like L3 or B1, then click() runs through DevTools.

∞

Stable IDs across navigations

Element references stay short and predictable as L1, B2, and L3. The loop stays getState() → LLM → click().

The agent loop

TideSurf keeps the loop simple: read compressed page text, decide, act, then call the next tool.

What ships in one package

TideSurf is a small TypeScript library for Bun and Node. It includes direct CDP tools, token budgets, tab lifecycle, content extraction, and MCP wiring.

Use read-only mode, path confinement, and input validation when you need guardrails. Built for engineers making function-calling browser agents.

Start building

Install, launch a browser, and read your first page in a few lines.

$ npm install @tidesurf/core
index.ts 
const browser = await TideSurf.launch()
await browser.navigate("https://example.com")
const state = await browser.getState()
$ npm install @tidesurf/core
connect.ts 
const browser = await TideSurf.connect()
await browser.switchTab(0)
const state = await browser.getState({ maxTokens: 500 })
